# Git Commit & Push Policy (User Directives)

1. **Commit Frequency Limit**:
   - Do NOT create micro-commits or commit excessively.
   - Target total commits across the project should be around 10 commits maximum.
   - Batch changes into meaningful milestones before committing.

2. **Push Policy (STRICT)**:
   - Perform the initial 1st push as requested.
   - **AFTER THE 1ST PUSH, NEVER RUN `git push` UNLESS THE USER EXPLICITLY INSTRUCTS TO DO SO.**
